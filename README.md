🎬 CineWatch – Movie Recommendation System

CineWatch is a content-based movie recommendation web application that suggests movies similar to a user’s preference using machine learning techniques.
The system is built with Python, Scikit-learn, and Streamlit, and follows a clean, modern UI inspired by popular streaming platforms.

🚀 Features

🎯 Content-based movie recommendation

🧠 Uses TF-IDF and Cosine Similarity

✍️ Handles misspelled movie names using difflib

🎚️ User-controlled recommendation limit (1–16 movies)

🎨 Modern dark-themed UI (Netflix-style)

🧭 Multi-section navigation: Home | Search | About

🌐 Web-based interface using Streamlit

🛠️ Technologies Used

Python 3

Streamlit – Web application framework

Pandas – Data handling and preprocessing

Scikit-learn – Machine learning (TF-IDF & cosine similarity)

NumPy – Numerical computations
